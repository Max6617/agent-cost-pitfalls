# Working notes

Provenance for the study, kept after the repository root was reduced to the files a first reader needs. Nothing here is required to verify `artifact/MANIFEST.json`. The public entry points stay at the repository root: `README.md`, `ARTIFACT.md`, `METHODS.md`, `PRE-REGISTRATION.md`, `PAPER.md`, `HISTORY.md`.

Filenames are unchanged. Checksummed analysis JSON still labels three of these documents by filename (`RERUN-PLAN.md`, `AA-PLACEBO-PLAN.md`, `PRE-REGISTRATION-HARD.md`); those files are under `notes/plans/`.

| folder | contents |
|---|---|
| `notes/handovers/` | Session handovers, the new-session brief, and the harness-onboarding note |
| `notes/defects/` | Defect write-ups, incidents, and the evidence-drift note |
| `notes/reviews/` | Hostile review rounds and the response |
| `notes/prompts/` | Prompts pasted into working sessions (literature, review, tasks, harness, related work) |
| `notes/plans/` | Plans, roadmaps, the run queue, and the hard-suite pre-registration |
| `notes/literature/` | Literature notes and the background surveys |
| `notes/status/` | Point-in-time session state, the day-one resume, and run alerts |
| `notes/records/` | Claim register, reconciliations, pilots, task-authoring notes, and operator guides (`RUNBOOK.html`) |
